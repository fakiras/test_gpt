# Монитор компьютера для iPad mini 1

Веб-панель для Safari на iOS 9. Сервер работает на наблюдаемом компьютере (Windows, Linux или macOS), iPad подключается к нему по Wi-Fi. App Store и сборка iOS-приложения не нужны.

## Запуск

Для Windows 10/11: установите Python 3.10+ с python.org и запустите `start-windows.bat` двойным щелчком. Скрипт создаст окружение, установит зависимость и запустит сервер. В окне будет показан вывод `ipconfig`: используйте IPv4 активного Wi-Fi или Ethernet адаптера. Ручной вариант ниже.

Установите Python 3.10 или новее на компьютер, скачайте этот репозиторий и откройте терминал в его папке:

```sh
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python server.py
```

Linux / macOS:

```sh
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

Компьютер и iPad должны находиться в одной локальной сети. Узнайте локальный IPv4 компьютера (`ipconfig` в Windows, настройки сети в macOS/Linux). Откройте в Safari на iPad `http://IP-КОМПЬЮТЕРА:8765`. При запросе брандмауэра разрешите Python только в частной сети. Гостевая Wi-Fi сеть может запрещать соединения между устройствами.

Можно добавить страницу на домашний экран через «Поделиться → На экран Домой». Компьютер должен оставаться включённым, сервер — запущенным. Остановка: Ctrl+C. Другой порт: `python server.py --port 9000`.

## Показатели

- Общая загрузка CPU и отдельных логических ядер.
- Использование оперативной памяти и системного диска.
- Суммарная скорость приёма и отправки по сетевым интерфейсам компьютера.
- Загрузка, температура и видеопамять первой NVIDIA GPU, если установлен драйвер с `nvidia-smi`. Для AMD/Intel пока выводится сообщение о недоступности; остальные показатели продолжают работать.

Сервер по умолчанию слушает все интерфейсы без пароля и шифрования. Используйте только доверенную домашнюю сеть; не пробрасывайте порт в интернет. Для доступа только с компьютера: `python server.py --host 127.0.0.1`.

Интерфейс использует XMLHttpRequest, JavaScript ES5 и простую вёрстку для старого Safari. Реальный iPad нужен для окончательной проверки совместимости. Приложение не требует внешних веб-сервисов.
